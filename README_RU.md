# Сайт Юрочки и Сонечки

## Как добавить фотографии, которые увидят все
1. Открой `public/images/` и положи туда фотографию, например `foto-01.jpg`.
2. Открой `public/images/gallery.json`. Добавь имя файла в список, например:
   ```json
   [
     "lyubimaya.jpg",
     "foto-01.jpg"
   ]
   ```
3. Загрузи изменённые файлы на GitHub. После публикации фото появится у всех посетителей.

## Как добавить песни (до 10)
1. Положи MP3/OGG/WAV в `public/audio/`, например `song-01.mp3`.
2. Открой `public/audio/tracks.json` и перечисли имена файлов:
   ```json
   [
     "song-01.mp3",
     "song-02.mp3"
   ]
   ```
3. Загрузи файлы и обновлённый JSON на GitHub.

Важно: в JSON нельзя добавлять комментарии, а после последнего имени файла не ставь запятую. Фотографии/песни, выбранные кнопками на самом сайте, сохраняются только в текущем браузере; чтобы они были доступны всем и на всех устройствах, добавляй их в папки проекта и обновляй JSON. Не загружай личные файлы, которыми не хочешь делиться публично: репозиторий и сайт Public доступны всем.

## Запуск локально
`npm.cmd install` затем `npm.cmd run dev`

## Сборка для GitHub Pages
`npm.cmd run build`
